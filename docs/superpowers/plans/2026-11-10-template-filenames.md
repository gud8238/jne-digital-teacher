# 서류양식 파일명 변경 대응

사용자가 영문 badge_id 접두어를 지운 6종 파일을 그대로 사용한다. Drive에서 확인한 현재 파일 ID를 배지 ID에 연결해 이후 표시 이름 변경에도 연결을 유지한다. 파일은 지정된 서류양식 폴더 안에 있고 HWPX인 경우만 선택한다. 기존 영문 접두어와 `배지명_취득 인증서류.hwpx`도 대체 탐색으로 지원하며, 고유 ID가 없고 후보가 중복되면 임의로 선택하지 않는다. 마스터 제외와 다운로드 내용 검증은 유지한다.

- [ ] 어댑터에서 현재 한글 이름·고유 ID 이름 변경·기존 접두어·중복·폴더 외 파일 경계를 검증한다.
- [ ] GAS 탐색 수정 후 전체 테스트·타입·린트·빌드와 독립 검토를 수행한다.
- [ ] 기존 GAS 배포를 CLI로 갱신하고 운영 6종의 파일명·바이트·다운로드 버튼을 확인한다.
- [ ] GitHub와 운영 기록을 갱신한다. Drive 파일의 이름·내용·공유 상태는 변경하지 않는다.
