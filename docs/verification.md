# 구현·검증 기록

2026-10-17, Asia/Seoul 기준입니다.

## 확인한 결과

- 단위·컴포넌트 테스트 35개 통과. 배지 계산, 잘못된 데이터, 세션, API 경계와 네 화면의 주요 동작을 포함합니다.
- TypeScript 검사, ESLint, Vite 제품 빌드 통과.
- 실제 GAS에서 배지 7종·잘못된 로그인 거절·테스트 계정 2개 분리·로그아웃 후 조회 거절 확인.
- 로컬 Netlify 중계 API에서 같은 실제 연결 검증 통과.
- 실제 시트를 사용하는 Playwright 브라우저 테스트 5개 통과. 360·390·768·1440px에서 로그인, 네 화면, 필터, 계정 전환, 새로고침 세션 유지, 가로 넘침을 확인했습니다. 별도 키보드 입력·보호 경로 복귀·큰 글꼴 검사도 통과했습니다.
- 운영 의존성 `npm audit --omit=dev --audit-level=high` 결과 취약점 0건.
- Google 렌더링 화면에서 교원·배지소개·배지별 수집현황 탭의 표, 드롭다운, 앞자리 0, 설명 줄바꿈을 확인했습니다. 기존 시트1은 보존했습니다.
- PC·모바일 스크린샷은 로컬 `artifacts/`에 저장합니다. 저장소에 개인정보·세션·인증 파일을 포함하지 않습니다.

첫 브라우저 검사의 도중 로컬 개발 서버가 종료되어 후속 4개 테스트가 실패했습니다. 서버를 재시작한 뒤 전체 5개를 다시 실행하여 모두 통과했습니다. 재시도 설정으로 실패를 숨기지 않았습니다.

## 시안에 의도적으로 적용한 변경

- 로그인은 사용자 요청에 따라 아이모두 버튼과 이메일 테스트 로그인만 제공합니다. Google·게스트 버튼을 제외했습니다.
- 모바일 하단 메뉴는 실제 제작 범위인 홈·배지소개·인증안내·나의 배지함 4개입니다.
- 예시 인물의 이름·학교·취득수·날짜는 가상 테스트 계정과 실제 시트 응답으로 바꿨습니다.
- 전체 배지 수는 7, 전문가 배지 수는 5이며 전체·전문가 달성률을 각각 계산합니다. 시안의 서로 다른 예시 숫자는 사용하지 않습니다.
- 전문가 3종 조건 충족과 실제 마스터 발급 기록을 구분합니다.
- 배지함은 단계별로 획득 배지를 먼저 배치합니다. 모바일에서 획득 3종을 첫 줄에 배치한 시안 구성을 따릅니다.

## 구현 중 결정과 영향

1. 현재 폴더에서 작업한다는 사용자 선택을 유지하고 기능 브랜치를 사용했습니다. main을 보호하기 위한 선택이며 마지막에 검증한 변경을 main으로 통합합니다.
2. GAS에 속성을 설정하는 REST API가 없어, 로컬에서 생성한 비밀값을 추적 제외된 임시 Setup.js로 Script Properties에 초기화했습니다. 초기화 후 파일을 로컬·현재 클라우드 소스에서 제거했습니다. 초기화 중에는 비밀값이 임시 서버 소스에도 존재했으며 Git과 화면 응답에는 포함하지 않았습니다.
3. 실제 GAS 실행에서 SpreadsheetApp.openById가 시트 편집 권한을 요구했습니다. 편집 권한을 확대하지 않고 Sheets REST API와 UrlFetchApp으로 조회하도록 바꿨습니다. 사용자에게 읽기·외부 연결 권한 승인을 받았으며 Sheets 서비스 활성화 후 실제 조회를 확인했습니다. 이 방식은 외부 요청 권한과 Sheets API 활성화가 필요합니다.
4. FE의 공통 App·스타일을 공유하는 작업 5~7은 기능별 테스트를 먼저 실패·통과시킨 후 일관된 빌드 한 커밋으로 묶었습니다. 실행 가능한 중간 상태를 유지하는 대신 해당 커밋의 검토 범위가 커집니다.

## 운영 제한

이 프로토타입은 나이스번호·이름 대조 방식입니다. 아이모두 실인증과 공식 배지 신청·심사·발급을 구현하지 않습니다. 배지 기준은 PPT의 잠정 기준입니다. 추천은 미획득 배지와 시트에 설정한 기본 순서로 표시하며 개인의 연수·증빙 이력을 추정하지 않습니다. 서버 캐시에서 세션이 제거되면 4시간 이내에도 다시 로그인해야 할 수 있습니다.

독립 코드 리뷰와 배포 후 확인 결과는 완료 시 이 기록에 추가합니다.
