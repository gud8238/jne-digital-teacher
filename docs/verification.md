## 구현 중 결정과 영향

1. 현재 폴더에서 작업한다는 사용자 선택을 유지하고 기능 브랜치를 사용했습니다. main을 보호하기 위한 선택이며 마지막에 검증한 변경을 main으로 통합합니다.
2. GAS에 속성을 설정하는 REST API가 없어, 로컬에서 생성한 비밀값을 추적 제외된 임시 Setup.js로 Script Properties에 초기화했습니다. 초기화 후 파일을 로컬·현재 클라우드 소스에서 제거했습니다. 초기화 중에는 비밀값이 임시 서버 소스에도 존재했으며 Git과 화면 응답에는 포함하지 않았습니다.
3. 실제 GAS 실행에서 SpreadsheetApp.openById가 시트 편집 권한을 요구했습니다. 편집 권한을 확대하지 않고 Sheets REST API와 UrlFetchApp으로 조회하도록 바꿨습니다. 사용자에게 읽기·외부 연결 권한 승인을 받았으며 Sheets 서비스 활성화 후 실제 조회를 확인했습니다. 이 방식은 외부 요청 권한과 Sheets API 활성화가 필요합니다.
4. FE의 공통 App·스타일을 공유하는 작업 5~7은 기능별 테스트를 먼저 실패·통과시킨 후 일관된 빌드 한 커밋으로 묶었습니다. 실행 가능한 중간 상태를 유지하는 대신 해당 커밋의 검토 범위가 커집니다.

## 독립 코드 리뷰와 수정

독립 검토자는 1588cbd..a80415a 전체 변경을 읽기 전용으로 검토했습니다. Critical 0건, Important 2건, 별도 수정이 필요한 Minor 0건이었습니다. 두 Important는 사용자에게 미치는 영향을 확인하고 한 차례 수정 과정에서 모두 해결했습니다. 추가 재리뷰를 요청하지 않았습니다.

2. 쿠키가 이미 없을 때 로그아웃이 401로 실패하는 문제: 쿠키 없는 로그아웃도 성공 처리하고 쿠키 삭제 응답을 반환합니다. `쿠키가 이미 없어도 로그아웃을 성공시키고 쿠키를 삭제한다` 테스트가 수정 전에 실패하고 수정 후 통과했습니다.
