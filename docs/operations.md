# 운영 안내

## 데이터와 기준

지정 구글시트의 `교원`, `배지소개`, `배지별 수집현황` 탭을 사용합니다. `시트1`은 보존합니다. 열 이름은 승인된 설계서와 `scripts/seed-data.mjs`의 headers를 따릅니다. 나이스번호는 텍스트로 입력해 앞자리 0을 보존합니다. 교원은 활성여부가 `사용`일 때만 로그인할 수 있습니다.

배지별 수집현황은 교원당 7종을 모두 입력합니다. 수집현황은 `획득` 또는 `미획득`, 취득일은 `YYYY-MM-DD` 또는 공란입니다. 미획득의 취득일은 공란으로 둡니다. 배지 또는 수집행이 누락·중복되면 API는 데이터 오류를 반환합니다.

PPT의 배지 기준은 잠정 기준입니다. 전문가 배지 3종은 마스터 조건 충족이며 마스터 배지 발급은 별도의 수집행으로 관리합니다. 공식 신청·심사·발급 기능은 없습니다.

## 테스트 계정

합성 테스트 데이터만 생성합니다. 나이스번호 `0000000001` / 이름 `테스트교원01`은 배지 3개(전문가 2개), `0000000002` / `테스트교원02`는 0개, `0000000003` / `테스트교원03`은 마스터 조건 충족·발급 전, `0000000004` / `테스트교원04`는 전체 획득입니다. 실제 교원 계정으로 오인하지 않도록 이름과 소속에 테스트 표기를 유지합니다.

## GAS와 서버 설정

GAS 프로젝트의 Script Properties에 `SPREADSHEET_ID`, `API_SHARED_SECRET`을 설정합니다. 웹앱은 배포자 권한·익명 접근으로 실행하되 doGet의 공유 비밀값 검증을 통과해야 데이터에 접근합니다. 공개 웹 화면에는 GAS 주소와 비밀값을 넣지 않습니다. GAS 기본 SpreadsheetApp.openById가 편집 권한을 요구하므로, 시트 편집 권한을 추가하지 않고 UrlFetchApp과 Sheets REST API로 읽습니다. 스크립트 권한은 스프레드시트 읽기와 외부 서비스 연결입니다.

Netlify Functions 환경에 `GAS_WEB_APP_URL`, `GAS_SHARED_SECRET`을 설정합니다. 로컬에서는 `.env.example`을 `.env`로 복사하고 값을 입력합니다. 비밀값·clasp 인증 파일·세션은 Git에 포함하지 않습니다. 서버 환경변수 변경 후에는 Netlify를 다시 배포합니다.

GAS 소스 변경은 `npx clasp push`, 버전 및 웹앱 갱신은 `npx clasp deploy --deploymentId <기존 배포 ID>`로 수행합니다. 실행 계정의 시트 읽기 권한 동의가 필요합니다. 토큰은 4시간 동안 유효하며 서버 캐시에서 제거되면 다시 로그인해야 합니다.

## 실행과 확인

의존성은 `npm ci`, 단위·컴포넌트 검증은 `npm test`, 타입 검사는 `npm run typecheck`, 린트는 `npm run lint`, 제품 빌드는 `npm run build`입니다. API를 포함한 로컬 실행은 `netlify dev`입니다. 실제 연결 없이 `npm run dev`만 실행하면 로그인 API를 사용할 수 없습니다.

프런트엔드의 기본 실행에는 가짜 사용자나 정적 API 대체가 없습니다. 연결 실패 시 화면에서 다시 시도하거나 환경설정을 확인합니다.
